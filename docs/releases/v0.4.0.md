# Development release 0.4.0

The final Windows build passed **371 native functional checks** and completed all five chapters through automated continuous navigation. [`DELIVERY_MANIFEST_v040.json`](../../game/evidence/v040/DELIVERY_MANIFEST_v040.json) binds the executable, frozen source, selected test results, and validated media. Earlier development runs remain historical evidence.

## What changed

The woods mill is now a connected physical problem. Cross a real bridge deck, climb its fence and steps, and load the large wheel with a child's weight. A creaking warning precedes the breakaway. The rigid wheel rolls and its actual travel pulls the gate clear. Both children need room to retreat; a companion left in front can be hurt. There is no held interaction that opens the gate in place of the sequence.

The five-chapter route extends to **79,200 authored world units**, compared with 56,000 in v0.3.0. Woods and school forks offer wet, quiet lower crossings, a shared pump that costs salvage, or a dry upper climb whose brace competes for that salvage. Upper food and medicine rewards are finite. Eighteen timed hazard lanes include two listening posts; shared lifting, clearing, bracing, light, falling debris and wind vary the journey.

Movement refinements include blended crouching, overhead clearance before standing, turn braking, support-foot locks, quiet settling and boot placement on slopes. New canal and mill paintings retain transparent layers; the wheel, gate and railing are separate runtime parts connected to their physical encounter.

The art consistency pass takes the painted tent's readable materials as its benchmark. Painted faces and clothing remain visible, with clearer skin, hair, and garment values, revised material tints, softer contact shadows, and restrained environmental darkness. This visual revision still needs artistic review; it does not establish AAA finish.

A separate freight-crossing rehearsal combines supplies, shelter, stealth, traversal, and shared lifting. It keeps its own save and does not replace the expanded five-chapter journey.

The survival pack holds four food portions, three salvage pieces and two medicines. World caches contain finite authored totals of 26 food portions, 18 salvage pieces and 13 medicines; those totals include optional routes and are not the starting inventory.

## Play or edit

Release assets on [GitHub](https://github.com/SingSongScreamAlong/WhenTheSkyClears/releases/tag/v0.4.0):

- **When_The_Sky_Clears_Windows_v0.4.0.zip**: extract and run **When the Sky Clears.exe**. No engine installation is needed.
- **When_The_Sky_Clears_Editable_Source_v0.4.0.zip**: import `project.godot` in Godot 4.6 Standard. Editor play requires no export templates. The source package and repository preset both keep custom-template fields empty.

The [repository guide](../REPOSITORY.md) covers engine setup and export. [`PLAY.cmd`](../../game/PLAY.cmd) launches the journey from a prepared checkout. [`MILL_PLAYTEST.cmd`](../../game/MILL_PLAYTEST.cmd), or the `-- --mill-preview` option, starts the mill directly in an isolated, unsaved playtest. [`FREIGHT_CROSSING.cmd`](../../game/FREIGHT_CROSSING.cmd), or `-- --freight-crossing`, opens the separate freight rehearsal. Use the normal launch for campaign saves. This version writes `journey_v4.json` in its separate `WhenTheSkyClears/v040` user-data directory and preserves earlier saves.

For macOS editor play, install Godot 4.6 stable Standard and import the same project. See the retained [macOS guide and verification limits](../MACOS.md). This release does not supply or claim validation of a macOS application package.

For Windows builds from the repository, run `python game/tools/setup_godot.py`, then `python game/tools/export_v040.py`. The export helper temporarily selects the portable templates and restores the preset before recording source identity. Manual editor or direct command-line exports instead need matching Godot 4.6 export templates installed through Godot.

Controls and detailed development notes are in [`DEVELOPMENT_v0.4.0.txt`](../../game/DEVELOPMENT_v0.4.0.txt); chapter staging is in [`JOURNEY_v0.4.0.txt`](../../game/JOURNEY_v0.4.0.txt).
