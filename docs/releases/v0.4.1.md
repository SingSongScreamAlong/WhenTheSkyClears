The final Windows executable passed **386 native functional checks**, its separate **27-check source animation fixture**, and verification of **12 fresh native 4K captures**. Continuous navigation completed all five chapters. The verified [v0.4.0 release](v0.4.0.md) and its frozen evidence remain preserved.

## Current changes

Six new painted props distinguish a ration box, medicine satchel, canvas tool roll, pump body, separate lever and lantern. The original 1536 × 1024 RGBA output retains alpha and its recorded generation prompt. Partial caches show only their remaining supplies; empty containers persist as search history. The pump lever moves at its bearing toward the working hands, and the sluice rises with the receding water. Clearing, bracing and shared lifting receive local work movement, with warmer lantern light at braces.

School, railway and ash regions use different architectural staging. Cleaner banks, bridge edges and foreground foliage leave more room to read the route. The mill refines its painted crop registration, chain, bearing and breakaway debris while preserving the connected physical sequence and risk to either child.

Work now interrupts when the player leaves its height, releases the input or loses the required companion. Interrupted shared work frees both children. Pause holds work and lever motion; pause and inventory also hold the water transition. The existing five chapters and survival choices remain; no additional chapter or measured human playtime is claimed.

Character and environment consistency continue to use the painted tent's material clarity as the benchmark. The native source and rendered output have been reviewed as development artifacts; user artistic acceptance remains separate. AAA finish is an ongoing target.

## Independent build and evidence

The new [`build_v041.py`](../../game/tools/build_v041.py) keeps this pass under `game/build/v0.4.1/` and `game/evidence/v041/`. It does not overwrite the v0.4.0 executable, ZIPs or evidence. Its metadata identifies the delivery snapshot as 0.4.1 while preserving existing runtime report labels and save behavior; the helper does not rewrite game source to change its version strings.

From the repository root, after the runtime and artwork are frozen:

```sh
python game/tools/setup_godot.py
python game/tools/build_v041.py export
python game/tools/build_v041.py test all
python game/tools/build_v041.py test capture
python game/tools/build_v041.py verify
python game/tools/build_v041.py package
```

Export temporarily selects the downloaded Windows templates and v0.4.1 product metadata, then restores the export preset byte for byte. Its identity records the complete runtime source hashes and exact executable hash. Native functional and continuous-journey tests use that executable. The expanded animation suite remains a separately bound native source fixture because it includes the baseline movement checks.

`test smoke survival` selects individual suites. `test movement-checks --source --tag source_movement` checks work in progress without claiming final executable verification. Rendered capture defaults to `--capture-v041`. Each scenario clears only recognized direct output files and records a fresh hash inventory; verification rejects missing or subsequently changed results. Optional `test mill-playthrough` records native mill frames; encoding and full decoding have their own validation record.

The verify operation writes nothing. Packaging requires passing smoke, survival, encounter, journey, optional-route, development-branch, movement, mill, story, freight-crossing and refinement suites, continuous traversal, the separate source animation fixture, and 12 native 4K captures. It writes separate Windows and editable-source ZIPs only after source and executable identities match.

The verified scope is **386 native checks** (371 earlier checks plus 15 refinements), a separate **27-check source animation fixture** that includes the baseline 13 movement checks, and **12 native 4K captures**.
