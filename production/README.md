# Historical Blender, artwork and film production

This production is distinct from both game implementations. `original/` follows the original WTSC production's relative folder structure. `additional/` preserves separately discovered named WTSC studies from earlier work. Original local files remain untouched.

Text scripts, design data and notes are tracked here. Large screened Blender files, original stills and silent review movies are supplied in numbered ZIP parts in the [preservation release](https://github.com/SingSongScreamAlong/WhenTheSkyClears/releases/tag/wtsc-preservation-2026-10-20). Extract all parts at the repository root to populate the same `production/` paths. Every part is independently extractable and includes its own file/hash list.

The archive includes provisional, rejected and superseded studies as development history. A filename containing `final`, `approved`, or a high version number does not establish current human artistic acceptance. Archived scripts are source records rather than an automatically callable current pipeline. Known machine paths and private Library identifiers were removed from distribution text; three Windows-1252 notes were converted to UTF-8.

163 Blender scenes passed the publication check for sound datablocks, sensitive embedded text, reference-name indicators, and packed image dependencies. Other scenes containing packed/unverified trailer music or private embedded records remain local. Silent review movies retain their original pixels and framing; no new rendering or art iteration was performed.

See [`../docs/consolidation/INVENTORY.csv`](../docs/consolidation/INVENTORY.csv) for precise inclusion, omission and pending reasons. This directory does not include a cleared trailer soundtrack, a finished game, a blanket asset license, or an assertion that every historical scene is production-ready.
