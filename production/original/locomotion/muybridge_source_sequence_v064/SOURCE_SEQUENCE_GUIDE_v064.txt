WTSC — twelve-phase manually authored source-motion study v064
2026-10-19

Purpose
This folder is an isolated study of the twelve side-view photographs in the top row of the retained Muybridge Plate 2 image. It is evidence for broad stride, support, and contact changes. It is not production character art, a continuous-frame animation, or a solution for the trailer's 75–80 second recovery shot. Earlier v062 and v063 trace folders remain preserved. No production scene, v045c art, world, music, title or other specialist file was edited.

Open and edit
Each native/Muybridge_PhaseNN_Manual_Trace_v064.blend is a separate Blender 5.2.2 LTS file. Open the file in Blender and select its "Phase NN Manual GP Contours" object. It has one Grease Pencil layer and one authored frame, at Blender frame 1. The actual curves can be edited point by point. Its companion source crop is reference/phaseNN_source_crop.png; its manually selected pixel point list is phase_specs/phaseNN.json. The files are independent. There are no animation keys, automatic inbetweens, procedural skeletons, or copied frames passed off as new drawings.

Each phase crop is exactly 310 x 588 RGB pixels, with source rectangle [31 + 310*(NN-1), 32, 341 + 310*(NN-1), 620]. The crops were pixel-compared to the original image and all twelve passed. Every source pixel point (x,y) maps to Grease Pencil local coordinates ((x-155)*0.01,(294-y)*0.01,0). Every native file uses a 620 x 1176 orthographic camera with ortho scale 5.88. This is a shared crop-space registration; the different camera-panel origins are not a character root-travel curve.

Artistic assessment
The repeated local scale, major foot contacts, support narrowing, swing reversal and wide-stride poses read coherently across the twelve source photographs. The v064 phase-8 hand was simplified from v063's comb-like fingers; its planted-foot dorsum and knee occlusion now have separate visible strokes. Many head and shoulder contours remain deliberately sparse because the source has blur and overlapping limbs. The linework is even, diagrammatic, and anatomically approximate at the hand and knee intersections. The adult photographic proportions and unpainted contours are not a suitable look for the boy and girl. This can guide observation of weight transfer, but it does not meet the requested cinematic character quality.

Production integration contract and unsolved work
There is no direct import contract into shots/world/WTSC_Open_Battlefield_Supported_Trial_v046.blend, because this source study has no authored trailer timing, no child-size design, no root travel curve, and no locked foot coordinates in the world scene. If a later character pass draws from these observations, production must independently specify phase timing at 24 fps, continuous root motion and world travel, planted-foot anchors, camera-space size, child proportions, differentiated intentions, material/painting treatment and hand-contact intent. The intended recovery-to-walking restart at about 78.3 seconds and genuine A/B/C visual performance studies remain outstanding. The original photograph cannot supply those decisions by interpolation alone.
